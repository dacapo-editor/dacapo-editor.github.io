Partita is free software under the [GNU GPL 3.0 or later](https://www.gnu.org/licenses/gpl-3.0.html). It is built on the work of these projects:

| Project | What it does in Partita | Author | License |
|---|---|---|---|
| [Bravura](https://github.com/steinbergmedia/bravura) | Music font (SMuFL) used to engrave the score | Steinberg Media Technologies | SIL Open Font License 1.1 |
| [FluidR3 GM](https://github.com/pianobooster/fluid-soundfont) | Instrument sounds for playback (downloaded on first use) | Frank Wen | MIT |
| [RustySynth](https://github.com/sinshu/rustysynth) | SoundFont synthesizer | Nobuaki Tanaka | MIT |
| [cpal](https://github.com/RustAudio/cpal) | Audio output | The RustAudio developers | Apache-2.0 |
| [Tauri](https://tauri.app) | Desktop application framework | The Tauri Programme | MIT or Apache-2.0 |
| [ureq](https://github.com/algesten/ureq) | Downloading the SoundFont | Martin Algesten and contributors | MIT or Apache-2.0 |
| [serde](https://serde.rs), postcard, crc32fast | Saving files and crash-recovery data | Their respective authors | MIT or Apache-2.0 |

A *partita* is a Baroque suite of pieces, like Bach's partitas for solo violin. Up to version 0.2.2 the project was called Partita. The project is inspired by the classic notation editors of the 1990s, such as Encore.

This website is built with [Astro](https://astro.build) and [Starlight](https://starlight.astro.build).
