In the app, **Help → Keyboard Shortcuts** (F1) shows this list too.

## Documents and view

| Keys | Action |
|---|---|
| `Ctrl` + `N` / `O` | New score / open a file |
| `Ctrl` + `S` / `Ctrl` + `Shift` + `S` | Save / save as |
| `Ctrl` + `W` | Close tab |
| `Ctrl` + `Tab` / `Ctrl` + `Shift` + `Tab` | Next / previous tab |
| `Ctrl` + `P` | Print |
| `Ctrl` + `=` / `−` / `0` | Zoom in / out / 100% |
| `Alt` | Move into the menu bar (`Alt` + letter opens a menu) |
| `F1` | Keyboard shortcuts |

## Entering music

| Keys | Action |
|---|---|
| `A`–`G` | Insert a note |
| `Shift` + `A`–`G` | Add a note to the previous chord |
| `R` or `0` | Insert a rest |
| `1`…`7` | Note value: 64th … whole |
| `8` / `9` | Breve / 128th (View → Breve and 128th Notes) |
| `.` | Toggle a dot |
| `+` / `-` | Raise / lower the accidental |
| `Alt` + `↑` / `↓` | Move the note one step |
| `Ctrl` + `Alt` + `↑` / `↓` | Move the note one octave |
| `Alt` + `1`…`4` | Switch voice |
| `T` / `S` | Tie / slur |
| `Ctrl` + `E` | Expression under the note (*dolce*) |
| `X` | Eraser on / off |
| `N` or `Esc` | Back to the Select tool |

## Lyrics

| Keys | Action |
|---|---|
| `Ctrl` + `L` | Write lyrics under the note at the caret (again to finish) |
| `Space` | Next note |
| `-` | Next note, joined with a hyphen |
| `_` | Hold the syllable (extender line) |
| `↓` / `↑` | Next / previous verse |
| `Esc` or `Enter` | Finish |

## Texts

| Keys | Action |
|---|---|
| `Enter` | Keep the text |
| `Shift` + `Enter` | New line (text boxes) |
| `Esc` | Leave the text as it was |

## Moving and selecting

| Keys | Action |
|---|---|
| `←` / `→` | One note |
| `↑` / `↓` | Staff above / below |
| `Home` / `End` | Start / end of the measure |
| `Ctrl` + `←` / `→` | Previous / next measure |
| `Ctrl` + `Home` / `End` | Start / end of the score |
| `Shift` + any of the above | Extend the selection |
| `Ctrl` + `A` | Select everything |

## Editing

| Keys | Action |
|---|---|
| `Backspace` / `Delete` | Delete before / after the caret, or the selection |
| `Ctrl` + `X` / `C` / `V` | Cut / copy / paste |
| `Ctrl` + `Z` | Undo |
| `Ctrl` + `Y` or `Ctrl` + `Shift` + `Z` | Redo |
| `Ctrl` + `Enter` | Insert a measure |

## Playback

| Keys | Action |
|---|---|
| `Space` | Play / pause from the caret |
| `Shift` + `Space` | Play from the beginning |
| `Esc` | Stop |
