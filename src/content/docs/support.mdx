Da Capo is free, with no paid edition, no trial and no subscription. Everyone gets the full app. If it helps you write music, you can help it grow.

## Donate

<Aside type="note" title="Coming soon">
Donations through **GitHub Sponsors** are being set up for the dacapo-editor organization. GitHub Sponsors charges no fees, so every cent goes to the project. This page will have the link as soon as it is ready.
</Aside>

## Other ways to help

<CardGrid>
	<Card title="Spread the word" icon="comment">
		Tell your choir, band, students or fellow arrangers about Da Capo.
	</Card>
	<Card title="Star the project" icon="star">
		A star on [GitHub](https://github.com/dacapo-editor/dacapo) helps other musicians find it.
	</Card>
	<Card title="Report problems" icon="warning">
		Found a bug or something confusing? [Open an issue](https://github.com/dacapo-editor/dacapo/issues). In the app, **Help → About Da Capo → Copy version info** gives us the details we need.
	</Card>
	<Card title="Contribute" icon="seti:rust">
		Code, documentation, translations and testing are all welcome.
	</Card>
</CardGrid>
