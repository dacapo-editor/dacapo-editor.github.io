Partita es gratis: sin edición de pago, sin prueba y sin suscripción. Todo el mundo tiene la aplicación completa. Si te ayuda a escribir música, puedes ayudarla a crecer.

## Donar

<Aside type="note" title="Muy pronto">
Las donaciones mediante **GitHub Sponsors** se están preparando para la organización partita-notation. GitHub Sponsors no cobra comisión, así que cada céntimo llega al proyecto. Esta página tendrá el enlace en cuanto esté listo.
</Aside>

## Otras formas de ayudar

<CardGrid>
	<Card title="Corre la voz" icon="comment">

	</Card>
	<Card title="Dale una estrella" icon="star">

	</Card>
	<Card title="Informa de problemas" icon="warning">

	</Card>
	<Card title="Contribuye" icon="seti:rust">
		Código, documentación, traducciones y pruebas: toda ayuda es bienvenida.
	</Card>
</CardGrid>
