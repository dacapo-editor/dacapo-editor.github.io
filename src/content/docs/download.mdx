Once installed, Da Capo updates itself: it tells you when a new version is out and installs it when you restart.

<Card title="System requirements" icon="laptop">

| | Minimum |
|---|---|
| **Windows** | Windows 10 or 11, 64-bit (x64). WebView2 is part of Windows 11; on Windows 10 the installer adds it if it is missing. |
| **macOS** | macOS 11 Big Sur or later, Apple silicon or Intel. |
| **Linux** | 64-bit (x86_64) with WebKitGTK 4.1: Ubuntu 22.04, Debian 12, Fedora 36 or newer. |
| **Memory** | 4 GB of RAM. |
| **Disk** | Under 30 MB for the app, plus 150 MB for the sounds, downloaded the first time you play. |
| **Screen** | 1280 × 720 or larger. A mouse or trackpad and a keyboard. |
| **Internet** | Only to download the sounds once and to check for updates. Da Capo works offline. |

## First start

<Aside type="caution" title="Security warnings">
The installers are not signed yet, so your system may warn you the first time:

- **Windows**: if SmartScreen says “Windows protected your PC”, click **More info → Run anyway**.
- **macOS**: if macOS says the app cannot be opened, go to **System Settings → Privacy & Security** and click **Open Anyway**.
- **Linux**: make the AppImage executable (`chmod +x`) and run it, or install the `.deb` or `.rpm` package.
</Aside>

**Sounds.** The first time you press Play, Da Capo offers to download its instruments (FluidR3 GM, 148 MB, once).

## Build it yourself

You can also build Da Capo from the source code.

<Steps>

1. Install [Rust](https://rustup.rs) (stable, 1.89 or newer) and the [platform dependencies for Tauri 2](https://v2.tauri.app/start/prerequisites/).

2. Get the code and run it:

   ```bash
   git clone https://github.com/dacapo-editor/dacapo.git
   cd dacapo
   cargo run -p dacapo
   ```

</Steps>

The full development setup is described in [INSTALLATION.md](https://github.com/dacapo-editor/dacapo/blob/main/docs/INSTALLATION.md).
